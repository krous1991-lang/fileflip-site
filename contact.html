We aim to make PDF and image conversion straightforward. If a tool does not behave as expected, contact us and we will review the details you provide.

What to include in your message

Tell us which FileFlip tool you used, whether you were converting a PDF or an image, and what you expected to happen. Include the browser name and version, your device type, and any error message shown on the page. If the issue happens repeatedly, list the steps that reproduce it.

Common troubleshooting steps

  • Refresh the page and try again with a current version of your browser.
  • Check that the file is in a supported format and within the size and page limits shown by the tool.
  • For large files, close other browser tabs and try a smaller file to check whether device memory is a factor.
  • Make sure your browser allows JavaScript and can load the required conversion libraries.

You can also review our About FileFlip page for an overview of the tools, and our Privacy Policy for information about file handling.

How we use a useful bug report

A clear report helps distinguish a file-format problem from a browser or device limitation. For example, tell us whether a PDF fails before the first page appears, whether only one page is missing, or whether the download completes but looks different from the source. For image conversions, mention whether the issue affects transparency, orientation, colour, or file size.

Please do not attach confidential documents. A short description of the file type, approximate size, page or image count, browser, and visible error is usually enough to begin investigating. If the issue can be reproduced with a non-sensitive sample file, mention that in your message.

Privacy when contacting support

Please do not send passwords, payment details, identity documents, or confidential source files by email. If a conversion problem involves a private document, describe the issue without attaching the document unless sharing it is essential and you have confirmed it is safe to do so.

For questions about the website, technical issues, or suggestions for improving a converter, use the email address above. Including clear troubleshooting details helps us understand the problem and respond more effectively.
