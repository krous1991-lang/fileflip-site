PNG Output: Resolution and File Size

PNG uses lossless image compression, which is useful for diagrams, interface screenshots, charts, and pages with sharp edges. It does not mean every PDF page will become a small file: high-resolution pages and photographs can produce large PNG images.

The quality setting controls the rendering scale. A higher scale creates more pixels and can preserve smaller visual details, but it also uses more memory and creates larger downloads. If a document has many pages, start with the standard or high setting and check the output before converting the entire file again.

Each converted page is an image. Text may no longer be selectable, and PDF links, forms, bookmarks, and other interactive elements are not carried over as interactive features.

Before Converting a Large PDF

  • Keep the original PDF so you can return to selectable text and document features.
  • Check that every page is upright and readable after conversion.
  • Large page counts and high rendering scales can require substantial browser memory.
  • Download and open a sample output to confirm that the resolution suits your use.

When PNG is the better output

PNG is a good choice when the page contains screenshots, charts, diagrams, interface elements, line art, or text that needs clean edges. Unlike JPG, PNG uses lossless image compression, so it does not add the same kind of lossy compression artifacts. This does not guarantee a small file: a high-resolution page or a photograph can create a much larger PNG than a JPG version.

Use the standard render scale for quick previews or pages that will be displayed at a modest size. Choose a higher scale when readers need to zoom into labels, fine lines, or small print. The higher setting creates more pixels; it cannot restore detail that was missing from the original PDF.

Practical checks for PNG exports

Open a few output images at 100% zoom and check thin lines, small labels, coloured backgrounds, and page edges. For a multi-page document, compare the number of downloaded images with the PDF page count. If the browser slows down or stops during a large conversion, try fewer pages or a lower scale, then process the remaining pages separately.

PNG versus JPG for a PDF page

Choose PNG for sharp graphics and text-heavy pages where edge clarity matters. Choose JPG for photographs or when smaller files are more important than pixel-perfect edges. Neither format remains an editable document: page text becomes part of the image and PDF links, forms, bookmarks, and accessibility information are not retained. If you need to preserve those features, keep and share the original PDF instead.
