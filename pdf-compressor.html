How to compress a PDF

  1. Select a PDF file from your device.
  2. Choose High, Balanced or Strong compression.
  3. Press the Compress PDF button and wait for processing to finish.
  4. Compare the file sizes and download your new PDF.

About PDF compression

FileFlip PDF Compressor reduces PDF file size by rendering each page and placing it into a new PDF using JPEG image compression. The result depends on the original document and the selected quality. A file is not guaranteed to become smaller.

Important: Because pages are converted to images, text may no longer be selectable or searchable. Links, forms, bookmarks, accessibility information and other interactive PDF features may not be preserved. Keep your original file if you need those features.

Frequently asked questions

Is this PDF compressor free?

Yes. You can use this PDF compressor for free.

Are my PDF files uploaded?

No. Processing takes place locally in your browser. Your selected PDF is not uploaded to our server by this tool.

Will every PDF become smaller?

No. The result depends on the original PDF and the selected quality. Some PDFs may become larger after compression.

Will the compressed PDF keep selectable text?

This tool converts pages into images. Text, links, forms and other interactive elements may no longer work as they did in the original document.

Is there a file size limit?

This page accepts PDF files up to 50 MB. Large or complex documents may need more memory and processing time on your device.
